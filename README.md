# FlowCommerce landing page

Landing page estática desarrollada con React, TypeScript y Vite. No incluye API, base de datos ni autenticación; el contenido y los controles son una representación visual del diseño.

## Ejecutar en Visual Studio Code

1. Instala Node.js LTS si aún no está instalado.
2. Abre esta carpeta en Visual Studio Code.
3. En Terminal → Nueva terminal, ejecuta:

   ```bash
   npm install
   npm run dev
   ```

4. Abre en el navegador la dirección local que muestra Vite (normalmente `http://localhost:5173`).

Para generar la versión estática optimizada: `npm run build`. Los archivos resultantes quedan en `dist/`.
